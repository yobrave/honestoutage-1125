# The Most Honest Outage Line

One status page line an AI agent publishes during a total server outage, 160 characters at most. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
